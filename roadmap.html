Project Scope & Gantt Timeline

Clear scope boundaries and an 8-week delivery schedule demonstrating how the simulation progressed from initial concept through MVP build, usability improvements, and portfolio release.

In Scope (MVP & v1.1 Release)

  • 10-Stage Lifecycle Highway: Interactive SVG progress map from Concept to Feature Expansion.
  • RACI Alignment Matrix: Live validation across 7 core product and governance stakeholders per stage.
  • Framework Deliverable Matching: Drag-and-drop validation tying BABOK, PMBOK, and Scrum artifacts to phases.
  • Guided Onboarding Tour: First-time user modal walkthrough and persistent header help button.
  • Local Progress Persistence: Browser storage so players can resume sessions without authentication.

Out of Scope (Deferred to v2.0)

  • User Accounts & Cloud Sync: Excluded to keep barrier to entry zero and avoid backend database costs.
  • Multiplayer Leaderboards: Not aligned with the core self-paced learning objective for v1.
  • Custom Scenario Builder: Deferred until user feedback confirms demand for industry-specific templates.
  • PDF Export Engine: Replaced with clean monospace text artifact previews for lightweight browser performance.
